# יוצר אפליקציות — smti.uk/apk

אתר שהופך אתר אחד או כמה אתרים לאפליקציית אנדרואיד סגורה (APK).

## איך זה עובד

1. **האתר** (`worker/`, Cloudflare Worker) מקבל את הטופס: שם, אתרים, כתובות נוספות, קוד הגדרות, מצב מסך וסמל. הוא שומר את הבקשה ב-D1 (`drive-pro`, בטבלאות `apk_jobs`, `apk_chunks` ו-`apk_meta` בלבד) ומפעיל את ה-workflow בגיטהאב.
2. **GitHub Actions** (`.github/workflows/build-apk.yml`) מושך את ההגדרות מהאתר, מכין סמל (שהועלה, או הסמל של האתר הראשון), בונה את האפליקציה וחותם עליה. בסוף הוא מעלה את ה-APK חזרה לאתר.
3. **האפליקציה** (`android/`) היא פרויקט Java קטן בלי ספריות חיצוניות, ומשקלה כ-25KB:
   - כמה אתרים מורשים, כולל תתי-האתרים שלהם, ואפשרות להגביל אתר לנתיב מסוים.
   - מסך בית עם כפתור לכל אתר, כשיש יותר מאתר אחד.
   - כתובות נוספות שמותר לעבור אליהן, אבל הן לא מופיעות במסך הבית.
   - מסך הגדרות נעול בקוד, שבו אפשר לשנות את רשימת האתרים ואת הקוד. אחרי 5 ניסיונות שגויים יש המתנה.
   - הורדת קבצים, העלאת קבצים, וידאו במסך מלא, וכפתור חזרה.
   - חותמת קבועה לכל הבניות. בנייה חוזרת עם אותו שם ואותו אתר ראשון מותקנת כעדכון.

## הגדרה חד-פעמית (רק בגיטהאב)

1. ליצור ב-GitHub טוקן מסוג **fine-grained** על המאגר `smt-ivr/smt-p`, עם ההרשאה **Actions: Read and write**.
2. ב-Settings → Secrets and variables → Actions של המאגר להוסיף שני סודות:
   - `APK_GH_TOKEN`: הטוקן מסעיף 1.
   - `APK_BUILD_SECRET`: מחרוזת סודית ארוכה כלשהי.
3. להריץ שוב את ה-workflow בשם Deploy (Actions → Deploy → Run workflow). הוא מעתיק את שני הסודות ל-Worker בכל פריסה.

אפשר גם לשים מפתח חתימה משלך בסודות `APK_KEYSTORE_B64` ו-`APK_KEYSTORE_PASSWORD`, עם alias בשם `smt`. אם הם לא מוגדרים, הבנייה הראשונה יוצרת מפתח ושומרת אותו ב-D1, וכל הבניות הבאות משתמשות בו.

## הגבלות

- עד 6 בניות לשעה לכל כתובת IP, ועד 60 ביום בסך הכול. אפשר לשנות בראש הקובץ `worker/src/index.js`.
- קבצים ובקשות נמחקים אחרי 7 ימים.
- החסימה חלה על מעבר בין דפים (קישורים, הפניות, טפסים וחלונות חדשים). תוכן שנטען בתוך דף מורשה, כמו תמונות, סקריפטים ומסגרות, לא נחסם.

## בנייה ידנית

```bash
cd apk-builder/android && cp app/src/main/assets/config.example.json app/src/main/assets/config.json && ./gradlew assembleRelease -PappName="שם" -PappId=uk.smti.app.test
```
